# Демо-превью Mini App

Самодостаточная HTML-страница с настоящими `webapp/static/*` текущего коммита, имитацией Telegram
(шапка «Назад/Закрыть», нижняя кнопка, alert/confirm) и вымышленными данными. Без initData, токенов и
реальных участниц; проверка подписи Telegram на сервере не затрагивается.

Режимы:

- **Новая участница** — весь онбординг с нуля. Ответы даёт `demo-backend.js`: повтор логики `webapp/app.py`
  для онбординга и экрана «до старта». Состояние — только в памяти вкладки.
- **До старта / Неделя 1 / Неделя 3** — ответы записаны `record.py` с настоящего API на демо-базе
  (включая все комбинации отметок «Сегодня»); чек-ин считается в браузере.

```bash
python tools/preview/record.py out/fixtures.json   # записать ответы API
python tools/preview/build.py out                  # собрать out/preview-12-weeks.html
python tools/preview/diff_backend.py               # сверить demo-backend.js с API (нужен node)
```

`diff_backend.py` прогоняет один сценарий (80+ запросов, включая ошибки) через настоящий API и через
`demo-backend.js` и сравнивает статусы и JSON. Меняешь эндпоинты онбординга — обнови `demo-backend.js`,
пока расхождений не станет 0.
